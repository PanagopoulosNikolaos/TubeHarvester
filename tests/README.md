# Tests Directory

## Directory Summary

This directory contains unit and integration tests for TubeHarvester. The test suite uses pytest and unittest.mock to validate backend downloaders, scrapers, batch executors, cookie managers, and NiceGUI UI components and views.

- [`test_batch_downloader.py`](../docs/tests_docs/test_batch_downloader_doc.md) — Tests for concurrent batch download operations

- [`test_cookie_manager.py`](../docs/tests_docs/test_cookie_manager_doc.md) — Tests for browser cookie extraction functionality
