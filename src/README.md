# TubeHarvester Source Documentation

## Directory Summary

This directory contains the source code for TubeHarvester. The architecture is cleanly divided into `extraction/` (backend logic, downloaders, scrapers, cookie management) and `ui/` (NiceGUI frontend components, views, and theme styling).

## Documentation Index

- `extraction/` — Backend extraction, downloading, and playlist/channel scraping logic
- `ui/` — NiceGUI frontend components, views, and Orange and Dark Soft design theme
- [`__init__.py`](../docs/src_docs/__init___doc.md) — Package initialization
